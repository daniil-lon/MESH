# IT Москва Колледж — PWA «МЭШ-Колледж»

Progress-Web-Приложение для студентов колледжа: расписание, оценки, посещаемость,
домашние задания, новости, чат, push-уведомления и личный кабинет. Работает в браузере
и как установленное приложение (PWA), а также как автономный Windows-EXE.

## Возможности

**Студент**
- Расписание занятий на день/неделю со звонками
- Оценки, средний балл, долги по предметам, рейтинг в группе, целевой калькулятор
- Посещаемость, замены, экзамены, расписание звонков
- Портфолио, учебная практика, курсовая, диплом, достижения (печать, PDF)
- Справка (автозаполнение + печать), электронный студенческий билет с QR
- Новости с лайками/комментариями, опросы, FAQ, материалы, кружки, бюро находок
- Чат приложения, заявки (тикеты) с ответами, расписание дежурств
- Погода, бесплатные аудитории, дни рождения, календарь (импорт в ICS)
- Пуш-уведомления (Web Push), напоминания, сводка, Pomodoro-таймер
- Офлайн-доступ (Service Worker), синхронизация настроек, смена пароля

**Преподаватель**
- Журнал оценок по предметам и группам, проставление оценок
- Контроль домашних заданий, отметка сдачи
- Посещаемость группы по дням
- Мульти-группы: один преподаватель может вести несколько групп
- Экспорт журнала в CSV
- Личное расписание занятий

**Куратор**
- Дашборд: посещаемость, оценки, заявки студентов, рейтинг
- Публикация объявлений в новости + push
- Ответы на заявки

**Администратор** (админ-панель `/admin.html`, PIN по умолчанию `1111`)
- Новости, замены, звонки, экзамены, столовое меню, расписание
- Текстовые файлы данных через админку, резервные копии (ZIP), версии файлов
- Импорт студентов и расписания из CSV, массовые операции
- Талочные push-рассылки, запланированные публикации новостей
- Статистика, топ групп по успеваемости, посещаемость групп
- Журнал действий и ошибок фронтенда

## Архитектура

- **Бэкенд:** Python + FastAPI (HTTP API, JSON-хранилище файлов)
- **Фронтенд:** чистый HTML/CSS/JS (PWA, Service Worker, Web Push)
- **Данные:** JSON-файлы в `backend/data/` (без внешней БД)
- **Хранилище зуба:** `backend/data`, `uploads/`, `backend/vapid_keys.json`,
  `backend/subscriptions.json` — исключены из Git

## Быстрый старт (локально)

```bash
pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
# или
python -m backend.uvicorn_launcher   # если таковой создан, иначе выше
```

## Деплой

### Vercel (бесплатный хостинг)

Проект уже настроен: `vercel.json` + `api/index.py` (a2wsgi). По каждой push-замене
в GitHub Actions деploy автоматически. Вручную:

```bash
vercel --prod
```

Приложение: https://mesh-psi.vercel.app (данные эфемерны: `/tmp`).

### Docker

```bash
docker compose -f deploy/docker-compose.yml up -d --build
# сервер на http://localhost:8000
```

### Windows EXE (офлайн-режим)

```bash
powershell -ExecutionPolicy Bypass -File desktop/build.ps1
# результат: dist\MeshCollegeApp.exe (встроенный сервер 127.0.0.1:8765)
```

### PythonAnywhere

См. `DEPLOY_PYTHONANYWHERE.md`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `MESH_BASE_DIR` | корень проекта | Корневая директория |
| `MESH_DATA_DIR` | `backend/data` | Хранилище данных |
| `MESH_UPLOADS_DIR` | `uploads` | Загруженные файлы |
| `MESH_KEYS_DIR` | `backend` | Каталог VAPID-ключей |
| `SECRET_KEY` | автогенерация в `data/.secret_key` | Подпись JWT |
| `ADMIN_TOKEN` | `1111` | PIN админ-панели |
| `VAPID_PRIVATE_PEM` / `VAPID_PUBLIC_B64URL` | автогенерация | Web Push |
