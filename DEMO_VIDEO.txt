СЦЕНАРИЙ ДЕМО-ВИДЕО «МЭШ Колледж» (PWA)
Продолжительность: ~2 мин. Запись экрана на телефоне (Chrome/Android).

0:00–0:20 — ВХОД
- Открыть приложение по HTTPS-ссылке (Vercel).
- Тап «Войти через МосАйДи» → реальный вход или демо-профиль.
- Показать: офлайн-баннер не появляется, всё живое.

0:20–0:45 — РАСПИСАНИЕ
- Нижняя навигация «Расписание».
- Переключить поток «Альфа/Бета» — расписание меняется (недели чередуются).
- Тапнуть по дню — показать пары, преподавателя, кабинет.
- Показать «Следующий урок» вверху.

0:45–1:05 — ЗВОНКИ И НОВОСТИ
- Экран «Звонки»: первая/вторая смена, разбивка по парам.
- Экран «Новости»: свежие новости колледжа.

1:05–1:25 — ОЦЕНКИ, ДОМАШКИ, ЗАМЕНЫ
- Оценки с фильтрами по предмету.
- Домашки с дедлайнами.
- Замены с переносом занятий.

1:25–1:45 — НАПОМИНАНИЯ И PUSH
- Включить уведомления (кнопка «Подписаться на push»).
- Разрешить уведомления в браузере.
- Показать локальное напоминание о домашке (таймер).

1:45–2:00 — ПРОФИЛЬ И ОФФЛАЙН
- Профиль с реальными данными аккаунта (имя, группа, курс).
- Выключить Wi-Fi → показать офлайн-баннер → расписание из кэша (Service Worker).
- Повторно открыть приложение без интернета — данные на месте.

ФИНАЛ: QR-код с ссылкой на работающий Vercel-деплой.
