# Деплой на Vercel (МЭШ Колледж)

## 1. Публикация бэкенда (FastAPI) — sandbox-режим
Vercel работает только с серверлесс-функциями, поэтому FastAPI запускается как единая функция.

1. Установите CLI и войдите:
   `npm i -g vercel` → `vercel login`
2. В корне проекта выполните `vercel` (первичная настройка):
   - Framework Preset → **Other**
   - Build Command → пустой
   - Output Directory → `.`
   - Root Directory → оставьте пустым (конфиг `vercel.json` уже есть)
3. Проверьте `vercel.json`: в проекте он настроен так, что все запросы `/api/*` и `/auth/*`
   передаются в `backend/main.py`, PWA-файлы отдаются со статики.
4. `vercel --prod`

> Важно: в серверлесс-среде `subscriptions.json` хранится в памяти и теряется при
> холодном старте. Для продакшена настройте Redis/базу — см. раздел «Продакшен».

## 2. Переменные окружения на Vercel
`vercel env add` для следующих ключей (требуются только для реального входа):
- `MOSAIDI_CLIENT_ID` — ID приложения МЭШ (МосАйДи)
- `MOSAIDI_CLIENT_SECRET` — секрет приложения
- `MOSAIDI_REDIRECT_URI` — например `https://mesh-college.vercel.app/auth/callback`
- `JWT_SECRET` — любая длинная строка
- `VAPID_SUBJECT` / `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` — только если не хотите
  автогенерацию. По умолчанию ключи генерируются автоматически и сохраняются в
  `/tmp/vapid_keys.json`.

## 3. HTTPS и push-уведомления
Vercel даёт бесплатный HTTPS. После деплоя:
- Service worker и Web Push заработают (при локальной разработке push на `localhost`
  не проверяется браузерами — нужен HTTPS).
- Подписка будет приходить в `/api/subscribe`, отправка — через `sendPush`
  в `push_service.py`.

## 4. Публикация фронтенда
Фронтенд отдаётся той же функцией (статика из корня). Ничего дополнительно
настраивать не нужно.

## 5. Проверка после деплоя
Проверьте, что отвечают:
- `/api/bells` — расписание звонков
- `/api/news` — новости колледжа
- `/api/profile` — реальный профиль (если есть токен МосАйДи, иначе демо)
- `/api/vapid-public-key` — публичный ключ push
- `/` — PWA-приложение

## 6. Данные МЭШ (реальные)
Реальные данные из МЭШ приходят, когда пользователь входит через МосАйДи
(страница `/auth/mosaidi`). Для этого нужно зарегистрировать приложение в
кабинете разработчика МЭШ и получить `CLIENT_ID`/`SECRET`. Без них используется
демо-режим с тестовыми данными.
