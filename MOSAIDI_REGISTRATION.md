# Регистрация приложения в МосАйДи (МЭШ)

Документ для деплоя реального входа в PWA «МЭШ Колледж».
Заполните поля в [скобках], отправьте заявку, впишите выданные ключи в `.env`.

---

## 1. Где регистрировать

МосАйДи = единый вход в сервисы ДИТ Москвы (mos.ru). Регистрация внешних
приложений — в **личном кабинете разработчика МосАйДи/МЭШ**
(`https://dev.mos.ru` → раздел «Мои приложения» → «Создать приложение»).

> Если у колледжа нет доступа к dev.mos.ru, обратитесь к администратору ИТ
> (через портал технической поддержки ДИТ или личного куратора в ГБПОУ).

## 2. Параметры приложения (что указать в заявке)

| Поле | Значение для этого PWA |
|---|---|
| Название | «МЭШ Колледж — расписание студента» |
| Тип | Мобильное веб-приложение / Web (OAuth 2.0) |
| Redirect URI | `https://<ваш-домен>.vercel.app/auth/callback` (после деплоя) или `http://localhost:8000/auth/callback` (локально) |
| Scopes | `openid profile` (минимум). Для доступа к МЭШ добавьте `mosh`/`mes` если предложит выбор данных |
| Согласие | «Доступ к персональным данным в целях: показа расписания, оценок и домашних заданий студента» |

## 3. Что получить и куда вписать

После одобрения заявки вы получите `CLIENT_ID` и `CLIENT_SECRET`.

```
# .env (рядом с backend/main.py)
MOSAIDI_CLIENT_ID=полученный_клиент_id
MOSAIDI_CLIENT_SECRET=полученный_секрет
MOSAIDI_REDIRECT_URI=https://<ваш-домен>.vercel.app/auth/callback
```

Затем перезапустите сервер. Кнопка «Войти через МосАйДи» в приложении начнёт
реальный OAuth-цикл: `/auth/mosaidi` → подтверждение на mos.ru → callback
с кодом → обмен на токен → в профиле появится реальное имя/курс/группа.
Внутри FastAPI это уже реализовано (роуты `GET /auth/mosaidi`,
`GET /auth/callback`, обмен кода на `data.mos.ru`).

## 4. Проверка после настройки

1. Откройте приложение → «Войти через МосАйДи».
2. Разрешите доступ на странице mos.ru.
3. Вернитесь — профиль должен показать ФИО, группу и курс (json-ключ
   `"real": true` в ответе `/api/profile`).

> До реальной регистрации работает демо-вход (кнопка «Демо-профиль»):
> заходит без пароля, показывает пример расписания/оценок. Push при этом
> тестовый.
